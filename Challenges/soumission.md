# Pour soumettre le TP2 (aka Challenges)

Envoyez le PDF de la presentation dans le repository de groupe dans une pull request.

Chaque presentation doit avoir
  1. premiere page: noms des membres, lien github avec le code
  2. presenter le design avant
  3. l’objectif de(s) nouvelle(s) fonctionalité(s)
  4. presenter le(s) design(s) apres
  5. des elements qui semblent importants/intéressants à racconter
