## Learn about collections in Pharo and their iterators
- A collection is a structure that contains objects. It used to facilate the manipulation of many objects such as adding an object, deleting...
- Collections in Pharo : 
    - OrderedCollection 
    - Array 
    - Set
    - Dictionnary
- To iterate in a collection we use a loop for example do.
- The difference between these collections is the way the objects are organized for example in Dictionnary we have key -> value, in Array on object per cell.
- Source of information : wiki.phobos-net & personal knowledge.
