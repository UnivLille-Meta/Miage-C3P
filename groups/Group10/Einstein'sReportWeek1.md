Week 1 – Pharo Installation and Setup

During my first week, I installed Pharo, a Smalltalk-based programming environment built around a purely object-oriented programming language.

The default download is the 64-bit version, which I used because my computer runs Windows 11.

```
https://pharo.org/download
```

I followed only the installation steps specific to this operating system.

```
https://pharo-project.github.io/pharo-launcher/installation/
```

If you want to reproduce the same setup or learn more about the installation process, you can find detailed instructions in the official documentation.
