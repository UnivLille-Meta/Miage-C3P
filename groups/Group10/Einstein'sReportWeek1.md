```
https://pharo-project.github.io/pharo-launcher/installation/
```

If you want to reproduce the same setup or learn more about the installation process, you can find detailed instructions in the official documentation.

2-Create my first image
I created my first image in Pharo. To do this, I opened Pharo Launcher and clicked on the New Image button.
Pharo Launcher creates images from templates, which are zip files that include the image and its related files (sources and changes).
Templates are grouped by categories, and the default one is Official Distributions.

I selected the current stable 64-bit Pharo image, which is the recommended version for most users. After creating it, I named the image and launched it to start working in the Pharo environment.
