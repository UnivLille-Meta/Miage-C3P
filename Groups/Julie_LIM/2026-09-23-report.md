Compte rendu de la troisième semaine - 23/09/2026 - EarthTutorial - FlagCountry

Aujourd'hui, j'ai terminé le tutoriel FlagCountry avec Pharo

J'ai appris à :

- utiliser Roassal avec  RSCanvas,  RSBox et RSSVGPath
- afficher la forme SVG d'un pays
- lire et parcourir le fichier world.svg avec XMLDOMParser
- créer la classe EarthMapCountry
- récupérer le nom, le code et le chemin SVG d'un pays depuis le fichier XML
- créer la classe EarthMap pour importer et stocker les pays
- afficher les pays dans un canvas Roassal
- créer une interface avec Spec grâce à EarthCountryBrowser
- récupérer les drapeaux depuis FlagCDN avec ZnClient
- afficher le code et le drapeau du pays sélectionné

L'application finale permet de sélectionner un pays dans une liste et d'afficher son code ainsi que son drapeau
