# Learn about conditionals in Pharo : 

Une collection est un objet qui regroupe plusieurs éléments.Les collections permettent de parcourir les éléments, de les rechercher, ou de les filtrer.

Les bibliothèques de Pharo : 

- Array (Pour les tableaux)  
- Set  
- Interval  
- String ( Pour les caractères)

Pour itérer sur des collections on utilise des méthodes comme :   
do : appliquer à chaque élément  
select : sélectionne les éléments de la condition  
collect : transforme les éléments et renvoie une nouvelle collection  
reject : enlève les éléments qui satisfait la condition   
detect : Trouver le premier élément

# Learn about conditionals in Pharo :

   
En Pharo, les conditionnelles sont envoyées comme des messages aux objets true et false IfTrue:IfFalse: .  
En java les conditions sont écrites de cette manière if {..} else {....} mais en pharo on utilise pas ces mots clés.  
Avantages : 

- En pharo le langage est plus cohérent et permet de traiter chaque opération comme un envoi de message .

Inconvénients : 

- C’est plus long d’écrire IfTrue:IfFalse: que d’écrire simplement if et else

# Learn about the basic Pharo coding style :

Pour avoir un code propre il faut suivre des règles : 

- Utiliser des noms simples et compréhensibles.  
- Pas de code dupliqué.  
- Ajouter une indentation pour le début du corps de la méthode.  
- Le paramètre ne doit pas commencer par une majuscule.  
- Les méthodes doivent être courtes comme des messages.

# Extras :
